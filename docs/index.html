把自己的目录变成论文标签

经管、其他学科，或学校、院系的认定名单，都可以自行导入。一份 CSV 是一组索引，每组独立命名，同一期刊可同时命中多组。需要扩展 0.13.0 或更新版本。

下载 CSV 模板 用 AI 整理名单 下载 0.13.0

  1. 准备要使用的名单

    使用机构发布的目录、学校文件、PDF 或表格，并确认适用年份。只有学科或评价体系名称时，先让具备联网能力的 AI 找到发布机构的原始名单，确认范围后再转换。

  2. 填模板，或让 AI 转成 CSV

    按固定四列填写，也可把下方提示词连同原始名单交给 AI，生成可下载的 CSV。模板中的“示例A”“示例B”仅演示格式，请替换为自己的等级。

  3. 核对后保存为 CSV UTF-8

    对照原目录抽查名称和等级，检查条目数量。ISSN 不确定就留空。Excel 中选择“CSV UTF-8（逗号分隔）”；AI 只返回文本时，将 CSV 代码块内的内容另存为 UTF-8 的 .csv 文件。

  4. 导入，并填写组名

    打开扩展弹窗 → 管理自定义索引 → 选择 CSV 文件。在“索引名称”输入框填写组名，例如“经管目录 2026”，检查预览后点击“导入索引”。刷新已打开的论文页，即可查看标签并按这组索引筛选。

CSV 固定四列

名称,等级,ISSN,别名
列名怎么填写
名称必填：期刊或会议的完整名称。
等级自由填写 A、B、重点等；留空显示“收录”。
ISSN选填，如 0025-1909；多个值用分号分隔。
别名选填：简称、其他名称；多个值用分号分隔。

“索引名称”就是组名，在管理页填写。CSV 的“名称”列用于期刊或会议，不用于填写组名。英文界面也使用这四个中文表头。

最多 30 组；每组最多 50,000 条，每个文件不超过 5 MB。目录保存在当前浏览器本地，可分别启停、导出备份和删除。

把这段提示词交给 AI

先把方括号里的内容换成你的要求，再连同名单文件或原文一起发送给常用 AI 工具。AI 用于整理、转换资料；生成后仍需对照原始名单核对。资料中的等级保留原样，无法确认的信息留空或单独列为待核项。

请根据我提供的原始名单，为“期刊会议等级与分区助手”创建一份可导入的 CSV 文件。

我的目标：[填写目录名称、适用年份和学科/机构范围]
资料：[上传 PDF/表格，粘贴名单原文，或提供发布机构的链接]
等级规则：[保留原目录等级；没有分级则留空；如需转换，明确写出对应关系]

请遵守以下规则：
1. 只根据提供且能够读取、核实的资料整理。先核对发布机构、年份和范围；链接无法读取时，请我提供文件或原文。
2. 表头必须依次为：名称,等级,ISSN,别名。不要增加其他列。每行只放一期刊或会议。
3. “名称”必填，使用完整期刊/会议名称；保留 Workshop、Findings 等限定词。“等级”按上述规则填写，未分级则留空。
4. ISSN 和别名选填。ISSN 保留为 1234-567X 这样的文本格式，不能确认就留空；多个 ISSN 或别名用英文分号分隔。
5. 不要凭记忆补充期刊、会议、等级、ISSN 或别名。相同来源的同等级重复行合并；同一名称、别名或 ISSN 对应不同等级时，单独列出冲突让我确认。
6. 输出逗号分隔的 UTF-8 CSV，优先使用带 BOM 的编码以便 Excel 打开。每个单元格用双引号包围，内容中的双引号写成两个双引号，空值写为 ""。
7. 组名不写进 CSV。我会在扩展管理页的“索引名称”输入框单独填写。
8. 优先提供可下载的 .csv 文件；若只能输出文本，请将 CSV 放在一个代码块内。数据来源、条目总数和待核项放在单独的说明中，不写进 CSV。

请先检查列数、名称是否为空、重复与等级冲突，再交付文件。
Create an importable CSV for Journal & Conference Rank Assistant from the source list I provide.

My goal: [list name, year, and subject or institution scope]
Source: [attach a PDF/spreadsheet, paste the original list, or give the issuing body's URL]
Tier rules: [preserve the original tiers; leave blank if unranked; state any requested mapping explicitly]

Requirements:
1. Use only supplied material you can read and verify. Check the issuer, year, and scope first. If a URL cannot be read, ask me for the file or original text.
2. Use exactly these four headers in this order: 名称,等级,ISSN,别名. Add no other columns. Each row represents one journal or conference.
3. 名称 is required and must contain the full venue name. Preserve qualifiers such as Workshop and Findings. Fill 等级 using my rules, or leave it blank if unranked.
4. ISSN and 别名 are optional. Keep ISSNs as text, such as 1234-567X. Leave uncertain values blank. Separate multiple ISSNs or aliases with semicolons.
5. Do not invent venues, tiers, ISSNs, or aliases from memory. Merge same-venue duplicates with the same tier. List conflicts involving a shared name, alias, or ISSN with different tiers separately for my confirmation.
6. Produce comma-delimited UTF-8 CSV, preferably with a BOM for Excel. Enclose every cell in double quotes, escape embedded double quotes by doubling them, and represent empty values as "".
7. Do not put the index group name in the CSV. I will enter it separately in Index name on the extension's management page.
8. Prefer a downloadable .csv file. If you can only return text, place CSV in a single code block. Keep sources, the entry count, and unresolved items in a separate note outside the CSV.

Check column counts, missing venue names, duplicates, and tier conflicts before delivering the file.
导入失败或网页没有显示？
  • 按导入页面显示的行号修正列数、空名称、ISSN 格式或等级冲突；用逗号分列、分号分隔多个别名。
  • 网页匹配的是期刊或会议来源。核对完整名称、网页使用的简称和可靠 ISSN；缺少来源信息时可能无法匹配。
  • 确认这组索引已启用，弹窗中的自定义标签显示已开启，并刷新论文页面。筛选时，同组所选等级取并集，不同组之间取交集。
